# Dev Time Tracker ⏱️

**Dev Time Tracker** is a powerful, lightweight WordPress plugin engineered specifically for developers, agencies, and freelancers who need precise tracking of development hours, project timelines, and auditing right inside their WordPress dashboard.

---

## 🚀 Key Features

* **Real-Time Tracking:** Seamlessly start and stop timers directly from your WordPress admin bar.
* **Project Management:** Organize logged time by client, project, or task categories (`class-dtt-projects.php`).
* **Robust Database Operations:** Custom database architecture ensures performant data logging and retrieval (`class-dtt-db.php`).
* **Audit & Privacy Compliant:** Comprehensive audit logging (`class-dtt-audit.php`) and built-in data privacy tools (`class-dtt-privacy.php`).
* **REST API Enabled:** Extend and integrate time-tracking data with external tools or custom front-ends effortlessly (`class-dtt-rest.php`).
* **Sleek Admin UI:** Integrated seamlessly into the native WordPress look and feel via dedicated styles and scripts.

## 📦 Installation

1. Download or clone this repository into your WordPress plugins directory (`/wp-content/plugins/`).
2. Navigate to your WordPress **Plugins** screen in the dashboard.
3. Locate **Dev Time Tracker** and click **Activate**.
